# Exam Card System

## Tujuan

Membangun aplikasi berbasis web untuk membantu Tata Usaha dalam mengelola dan mencetak kartu ujian siswa.

---

## Aktor

### Admin TU

- Login
- Mengelola data siswa
- Import data siswa dari Excel
- Mengubah status kartu ujian
- Mengatur periode ujian
- Mengatur ruang ujian
- Mengatur sesi ujian
- Mencetak kartu ujian
- Melihat riwayat pencetakan

---

### Siswa

- Memasukkan NIS/NISN
- Melihat status kartu ujian
- Mencetak kartu ujian jika sudah disetujui

---

## Status Kartu

- Draft
- Pending
- Ready
- Printed
